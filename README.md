> ## 🔒 Protección, Cifrado Avanzado y Portabilidad Segura para Windows 10 & 11
>
> USB Vault Pro es una potente aplicación de seguridad para Windows diseñada para proteger información confidencial almacenada en memorias USB mediante cifrado de nivel militar.
>
> Permite crear bóvedas cifradas que almacenan carpetas y archivos dentro de un único archivo protegido, utilizando cifrado **AES-256-GCM** y derivación de claves **Argon2id** para garantizar la máxima confidencialidad e integridad. >
> Ideal para profesionales, empresas, estudiantes o cualquier persona que transporte datos sensibles en unidades portátiles y requiera protección contra pérdidas o robos.

# ✨ Funciones incluidas en esta versión

USB Vault Pro 1.0.0 es la primera versión oficial del proyecto e incorpora un sistema completo de cifrado portatil, resguardo de datos y gestión de bóvedas para Windows.

### 🛡️ Bóvedas Cifradas con AES-256-GCM & Argon2id

Permite empaquetar e hiper-proteger archivos y carpetas completas dentro de un contenedor único e inexpugnable.

El sistema utiliza algoritmos de cifrado de estándar gubernamental y militar para asegurar que nadie sin la clave pueda acceder a tu información.

Al cerrar la bóveda, los archivos temporales se destruyen de forma segura, evitando cualquier rastro en la memoria o en el sistema.

### 🔄 Respaldo Automático y Protección contra Expulsión

Incluye un sistema inteligente de monitoreo que protege la integridad de tu memoria USB y de tus archivos.

Cuenta con respaldo automático de las bóvedas para evitar pérdida de información y previene la corrupción de datos ante expulsiones o formateos accidentales de la unidad.

Esta función es ideal para:

* 🏢 Entornos corporativos y trabajo remoto
* 🎓 Estudiantes y docentes con información académica
* ⚖️ Abogados, contadores y profesionales de la salud
* 🎒 Usuarios que transportan información sensible a diario

### 🔑 Autenticación Inteligente por PIN y Clave Maestra

Incorpora una doble capa de acceso que combina la comodidad de un PIN rápido con la máxima seguridad de una clave maestra.

Permite acceder rápidamente a tus carpetas cifradas sin comprometer la seguridad general del sistema ni la licencia digital asociada.

# ⚠️ Nota de Seguridad

> [!CAUTION]
> USB Vault Pro interactúa directamente con el sistema de archivos de Windows y la estructura de memoria USB para realizar el cifrado en tiempo real y prevenir expulsiones accidentales.
>
> Debido a este comportamiento técnico y al uso de algoritmos de cifrado de bajo nivel, algunos antivirus o soluciones de seguridad pueden mostrar alertas preventivas o falsos positivos.

> [!NOTE]
> USB Vault Pro es un proyecto independiente en constante evolución.
>
> Esta primera versión oficial aún no cuenta con una firma digital de código (Code Signing Certificate), por lo que Windows SmartScreen puede mostrar advertencias preventivas al ejecutar el archivo descargado.
>
> Estas advertencias forman parte de las medidas de seguridad estándar de Windows y no indican la presencia de software malicioso.
>
> La incorporación de firma digital se encuentra prevista para futuras versiones del proyecto.

# 📥 Instalación y Advertencia de Windows SmartScreen

> [!IMPORTANT]
> Al descargar USB Vault Pro, Windows puede mostrar la advertencia **"Windows protegió tu PC"**.
>
> Este comportamiento es normal cuando una aplicación descargada desde Internet aún no dispone de una firma digital reconocida por Microsoft.

2. Haz clic en **Ejecutar de todas formas**.
